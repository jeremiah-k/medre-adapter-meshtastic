# Changes

Merged PR descriptions and generated release notes are the primary change
record. Routine changes do not require numbered fragments. Optional operator
or coordinated-release notes may use descriptive filenames under `unreleased/`.

The [0.1.0 release](https://github.com/jeremiah-k/medre-adapter-meshtastic/releases/tag/0.1.0)
is published. Its 25 individual notes are retained in
[the release archive](releases/0.1.0/) as historical context. Notes written after
that tag remain unreleased; do not treat them as part of the published artifact.
